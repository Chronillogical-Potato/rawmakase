RAWmakase 0.1.4 improves the editing workflow: app settings have their own Preferences window, History names each edit, and a new Export dialog remembers your choices. Exports run in the background so you can keep editing, with controls for file naming, image size and the metadata included in the result.

## New

- **A dedicated Preferences window.** Open the gear in the top bar, or press Cmd+, on Mac / Ctrl+, on Linux. Camera and lens profiles, presets, demosaic selection, caches, the monitor profile and catalog information now live together, leaving the Settings menu focused on the current photo.
- **An Export dialog with remembered choices.** Choose the destination, file naming, JPEG or TIFF settings, long-edge resizing and metadata before exporting. Open it with Shift+Cmd+E on Mac or Ctrl+Shift+E on Linux.
- **Export with Previous.** Repeat your saved export settings without reopening the dialog, using Option+Shift+Cmd+E on Mac or Ctrl+Alt+Shift+E on Linux.

## Improved

- **Keep editing while an export runs.** Exports run in the background, with progress and cancellation in the top bar. They load the full-size source even when the editor has only loaded a quick preview.
- **See what changed in History.** Steps now show the control or action, such as Exposure, Sharpening, a preset or a crop, with the new value where applicable. Click a step to return to it; later steps remain dimmed and available until you make a new edit. Your local steps appear above imported Lightroom history.
- **Choose how to handle an existing export.** Overwrite it, use a unique filename or skip it, with a default behavior available in the Export dialog.
- **Control the metadata in exported files.** Exports can carry camera and capture EXIF, location data, Camera Raw XMP edit settings, and ratings, color labels and keywords. Camera metadata is read from the source RAW, including the preview JPEG inside Fujifilm RAF files.

## Changed

- **Reset All Settings is the single reset command.** Use Shift+Cmd+R on Mac or Ctrl+Shift+R on Linux. The separate Reset to Lightroom Edit menu item has been removed; imported Lightroom edits are still applied when the photo opens.

## Requirements

Mac downloads require macOS 15+. Linux packages are for x86_64: Ubuntu 24.04+ or Debian 13+, Fedora 43+, or current Arch Linux. AUR publication remains paused; the Arch package is available directly above.
