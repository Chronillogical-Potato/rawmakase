RAWmakase 0.4.4 is a bugfix release. It corrects imported zoom-lens profiles and Canon EF lens matching, keeps long Synchronize Folder confirmations inside the window, and stops double-clicks in Preferences from leaving the Loupe. On macOS, RAWmakase now has native File, Edit, View, Window and Help menus.

## New

- **Native macOS menus.** File, Edit, View, Window and Help menus, plus **Preferences…** in the application menu, run the same commands as the toolbar and shortcuts. Items are unavailable while a dialog or job blocks them, and **Close Window** and **Quit** still ask about unsaved work. ([#625](https://github.com/pch/rawmakase/pull/625))

## Improved

- **Adding a folder shows that folder.** After **Add Folder…** or dropping folders onto the window, the Library selects the imported folders and their subfolders and clears the filter bar, so the new photos are not hidden among other photos or by old filters. ([#625](https://github.com/pch/rawmakase/pull/625))
- **Folder context menus match the rest of the Library**, and the folder tooltip that appeared on every hover is gone. ([#625](https://github.com/pch/rawmakase/pull/625))

## Fixed

- **Imported zoom-lens profiles correct properly at every focal length.** Profiles such as Canon's EF 100–400mm could apply extreme radial distortion, vignetting or colour fringing corrections at longer focal lengths, or be rejected. Each calibration is now evaluated at its own scale before interpolating between focal lengths and apertures. ([#618](https://github.com/pch/rawmakase/pull/618), [#614](https://github.com/pch/rawmakase/issues/614))
- **Canon EF lens profiles match RAWs that write the lens name differently.** Some cameras, such as the EOS 5D Mark II, put a space after `EF`, so Default and Auto found no imported Adobe profile and the warning wrongly said none was imported. Lens versions and mounts are still kept apart, and the warning now reads "No matching imported Adobe lens profile". ([#612](https://github.com/pch/rawmakase/pull/612), [discussion #610](https://github.com/pch/rawmakase/discussions/610))
- **The missing-photo confirmation stays inside the window.** When Synchronize Folder removes many photos that hold edits, their list now scrolls, and the title and **Cancel**/**Remove** buttons stay visible. ([#626](https://github.com/pch/rawmakase/pull/626), [#624](https://github.com/pch/rawmakase/issues/624))
- **Double-clicking in Preferences no longer switches the Loupe to Grid.** Only double-clicks on the photo itself go back to the grid. ([#627](https://github.com/pch/rawmakase/pull/627), [#615](https://github.com/pch/rawmakase/issues/615))

## Upgrade notes

- Photos corrected with an imported zoom-lens profile may look different, most noticeably at longer focal lengths, because the profile is now applied as calibrated. Saved slider values are preserved.

Thanks to [@AlanH614](https://github.com/AlanH614) for reporting the lens profile problems ([#614](https://github.com/pch/rawmakase/issues/614), [discussion #610](https://github.com/pch/rawmakase/discussions/610)), [@Ricci36](https://github.com/Ricci36) for the synchronization dialog ([#624](https://github.com/pch/rawmakase/issues/624)) and [@luclu](https://github.com/luclu) for the Preferences double-click ([#615](https://github.com/pch/rawmakase/issues/615)).
