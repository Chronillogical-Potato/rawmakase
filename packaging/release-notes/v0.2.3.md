RAWmakase 0.2.3 is a smaller release that fixes problems found since 0.2.2. You can now import large Lightroom catalogs, open Canon and Nikon small RAWs, and finish the AI mask download on a slow connection. On Linux, the app starts on Intel + NVIDIA laptops, the AI masks work in the Arch package, and on Wayland the interface follows your desktop's text size. The Sony A7R VI also gets its own camera calibration.

## New

- **Open Canon sRAW and mRAW, and Nikon small RAWs** ([#381](https://github.com/pch/rawmakase/pull/381)). These files were refused with "Only three-color Bayer and X-Trans RAW files are supported". They now open and develop like other RAWs, with the usual white balance controls. They were checked against the camera's own JPEG on a range of Canon bodies from the 5D Mark II to the 1D X Mark II, and on the Nikon D810. The Demosaic setting doesn't apply to them, since they have no color mosaic. Thanks to @rauanvsc for the request ([#380](https://github.com/pch/rawmakase/issues/380)).
- **Sony A7R VI calibration** ([#378](https://github.com/pch/rawmakase/pull/378)). The A7R VI now has its own baseline exposure and white balance calibration, taken from Adobe's DNG Converter, instead of a generic Sony default. Without them, a custom white balance could be noticeably off in red and blue.
- **The interface follows the desktop's text size on Linux (Wayland)** ([#377](https://github.com/pch/rawmakase/pull/377)). When you change the text size in GNOME (Large Text) or with `omarchy display text size`, RAWmakase zooms its whole interface to match, also while it is running. On X11 the system already applies this through the display scale, so nothing changes there. Thanks to @lszl84 for implementing it.

## Fixed

- **Import Lightroom catalogs of 1 GB and larger** ([#383](https://github.com/pch/rawmakase/pull/383)). Catalogs of 2 GB or more were refused with "Catalog is too large for this importer", and those between 1 and 2 GB failed during the import. They now import with all photos, develop settings, keywords, ratings, labels, collections and history. For a catalog over 900 MB, the new RAWmakase catalog doesn't keep an exact copy of the original `.lrcat` inside it, so keep your Lightroom catalog. Thanks to @dmortell for the fix.
- **The app starts on Linux laptops with Intel and NVIDIA graphics** ([#376](https://github.com/pch/rawmakase/pull/376)). On these laptops RAWmakase picked the NVIDIA GPU, which couldn't draw the window, and crashed on startup. It now uses the GPU your system lists first, usually the one driving the display. To use the NVIDIA GPU, start it with `prime-run` or `DRI_PRIME=1`, as with other Linux apps. `WGPU_POWER_PREF` and `WGPU_ADAPTER_NAME` work again too. Thanks to @ZEROLINGG for the report ([#375](https://github.com/pch/rawmakase/issues/375)).
- **The AI mask download finishes on slow connections** ([#373](https://github.com/pch/rawmakase/pull/373)). A model file that took more than a minute to arrive was cut off and restarted from zero, so on a slow connection the download could never finish. It now continues where it stopped, also after a cancel or a restart of the app. If it does fail, the reason is shown above the Download button. Thanks to @EttVenter for the report ([#369](https://github.com/pch/rawmakase/issues/369)).
- **AI masks work in the Arch Linux package** ([#372](https://github.com/pch/rawmakase/pull/372)). The Arch package now includes ONNX Runtime, like the other packages, so Select Subject, Sky and Background no longer need `RAWMAKASE_ORT_LIB` there ([#368](https://github.com/pch/rawmakase/issues/368)).

## Requirements

Mac downloads require macOS 15+. Windows downloads are for 64-bit Windows 10 and later (x86_64). Linux packages are for x86_64 and ARM (aarch64): Ubuntu 24.04+ or Debian 13+, or Fedora 43+. The Arch Linux package is x86_64. AUR publication remains paused, so get the Arch package from the link above. Homebrew users update with `brew upgrade --cask rawmakase`. On Apple Silicon Macs and with the Windows installer, 0.2.2 offers this update in the app.
