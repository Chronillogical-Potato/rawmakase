# Native dependencies

Source builds dynamically link the system `libraw_r`, `lcms2`, C++ runtime and OpenMP runtime. LibRaw is separately licensed under LGPL-2.1/CDDL alternatives; see the installed package and [upstream license files](https://github.com/LibRaw/LibRaw). Little CMS and Rust dependencies retain their own licenses. The project's MIT license applies to RAWmakase's original code, not those libraries. Do not bundle native libraries without their notices and applicable distribution requirements.

Release DMGs and DEB/RPM packages bundle private copies of LibRaw and Little CMS 2.19.1, with their notices; the Windows build links the same versions statically. LibRaw is built from master commit [`4f01440`](https://github.com/LibRaw/LibRaw/commit/4f0144031c4adfadf7e053937826c49ed80cfa89) (2026-10-02), newer than the 0.22.2 release: it adds the Sony A7 V (ILCE-7M5), Sony A1 II (ILCE-1M2) compressed ARW6 files, Canon EOS R50 V and Hasselblad X2D II 100C, and carries every fix in 0.22.2 plus later decoder hardening. Master still reports itself as 0.22.0; the licence (LGPL-2.1 or CDDL-1.0) is unchanged. The native source archives and build script are attached to the GitHub release. Mac apps also bundle their non-system runtime dependencies; Linux packages retain system C++/OpenMP/graphics dependencies. Arch packages continue to use system libraries, so they open those cameras only once Arch's LibRaw does. See [release packaging](../packaging/RELEASING.md).

Subject selection runs Segment Anything 2.1 (Hiera small; Meta AI, Apache-2.0 code and weights) in the Hugging Face `onnx-community` ONNX export, through ONNX Runtime 1.23.2 (MIT; the packages' `licenses` carry its LICENSE and ThirdPartyNotices), opened lazily by `rawmakase-inference` from beside the executable. The runtime is bundled per package by `packaging/onnxruntime.py` (pinned archive and SHA-256 per platform, 1.23.2 being the last release with an official macOS x86_64 build); Arch source packages do not include it. The model files are not bundled: the app downloads four files from `onnx-community/sam2.1-hiera-small-ONNX` at a pinned commit (see `rawmakase-inference/src/manifest.rs`), each verified by SHA-256 before it is used. The export repository declares no license of its own; the weights' Apache-2.0 comes from `facebook/sam2.1-hiera-small`.

Rust dependencies are resolved in Cargo.lock. The UI uses eframe, pinned to the exact version in `Cargo.toml` (0.36.2 at the time of writing) because egui releases change behavior between patch versions; wgpu provides the GPU compute path. Build.rs verifies LibRaw >=0.22 and Little CMS through pkg-config. The tested native versions are LibRaw 0.22.2, the master commit above, and Little CMS 2.19.

On macOS, Apple Clang uses LLVM `libomp` and libc++; Linux keeps GCC OpenMP (`gomp`). The build corrects LibRaw pkg-config entries that still name the obsolete macOS `stdc++` library. Apple Silicon was verified with LibRaw 0.22.0 and Little CMS 2.17.

`src/camera_profiles/dng_tone.rs` contains the default ACR3 tone table from Adobe DNG SDK 1.7.1 `dng_render.cpp`, Copyright 2006–2023 Adobe Systems Incorporated, and `src/camera_profiles/temperature.rs` adapts the temperature table from `dng_temperature.cpp`, Copyright 2006–2019 Adobe Systems Incorporated. Their license is included in `licenses/Adobe-DNG-SDK.txt` and in the app bundles and packages. No Adobe camera or lens profiles are bundled; the user imports their own.

eframe's `default_fonts` feature compiles egui's bundled fallback fonts into the binary through the `epaint_default_fonts` crate, pinned at 0.36.2 by the eframe pin. Its four fonts are redistributed here, so their licenses are shipped alongside ours: Hack (`licenses/Hack-MIT-BitstreamVera.txt`, MIT with the Bitstream Vera and public domain DejaVu notices), Noto Emoji (`licenses/NotoEmoji-OFL.txt`), Ubuntu Light (`licenses/Ubuntu-UFL.txt`) and the emoji icon font (`licenses/emoji-icon-font-MIT.txt`). The four texts are copied verbatim from that crate's `fonts/` directory.
