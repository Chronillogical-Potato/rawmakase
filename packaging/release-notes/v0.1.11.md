RAWmakase 0.1.11 adds **virtual copies** you can create, rename, promote and remove, Lightroom's **Remove Chromatic Aberration**, a **Fringe Color Selector** with a Defringe that now matches Camera Raw, and an **XPan 65 × 24** crop. The Library opens and shows thumbnails much faster from network shares. RAWmakase also asks once whether you'd like to share an anonymous weekly usage report; it stays off unless you agree.

## New

- **Virtual copies.** **Create Virtual Copy** (**⌘' / Ctrl+'**, or the thumbnail menu in Library and Develop) makes a copy of any photo that starts from its current edit, rating, flag, label and keywords, named Copy 1, Copy 2 and so on. In Develop the new copy opens straight away. The thumbnail menu also has **Set Copy as Master** and **Remove Virtual Copy…**, which asks first and never touches the file. Copy names can be edited in the Metadata panel. Each copy now has its own Library thumbnail. Stacking copies under their master isn't supported yet ([#31](https://github.com/pch/rawmakase/pull/31)).
- **Remove Chromatic Aberration.** Lens Corrections has Lightroom's checkbox. It measures colour fringing in the photo itself, so it also works with adapted manual lenses. Lightroom edits and catalogs with it turned on, which were previously rejected, now import and render with it, and XMP export writes it ([#30](https://github.com/pch/rawmakase/pull/30)).
- **Fringe Color Selector.** An eyedropper at the Defringe heading sets the Purple or Green hue range from a fringe you click, as in Lightroom ([#33](https://github.com/pch/rawmakase/pull/33)).
- **XPan crop.** The crop Aspect list has **65 x 24 (XPan)** ([#29](https://github.com/pch/rawmakase/pull/29)).
- **Optional anonymous usage stats.** After first-run setup, RAWmakase asks once whether to send one anonymous report a week: the version, operating system and release, CPU architecture, how it was installed and the graphics backend, plus the distribution and display server on Linux. There's no identifier, and no files, photos or settings. The question shows the exact report, nothing is sent unless you choose **Share**, and **Preferences > General** changes the answer. `DO_NOT_TRACK=1` turns it off. Totals are public at [stats.rawmakase.com](https://stats.rawmakase.com); see [docs/usage-stats.md](https://github.com/pch/rawmakase/blob/v0.1.11/docs/usage-stats.md) ([#44](https://github.com/pch/rawmakase/pull/44), [#45](https://github.com/pch/rawmakase/pull/45)).

## Improved

- **Defringe matches Camera Raw.** At the same settings, Defringe now removes purple and green fringes about as strongly as Camera Raw. Before, Amount 5 barely changed a fringe Lightroom removes ([#33](https://github.com/pch/rawmakase/pull/33)).
- **Faster Library on network shares.** A cached thumbnail is now checked with a single file stat instead of re-reading part of the original, and the Library opens straight away, marking offline originals once a background check finishes. On a Synology share with about 8,000 photos, checking a cached thumbnail went from 60–74 ms to 5–9 ms per photo, and a catalog with 208 folders no longer waits 5.4 s to open ([#35](https://github.com/pch/rawmakase/pull/35)).
- **Smoother cropping.** Opening the Crop tool shows that photo's own aspect (Original, the matching preset, or its exact ratio as Custom) instead of the last photo's. When the crop changes, the previous picture stays in place, clipped to the new frame, until the new render is ready, instead of briefly stretching ([#29](https://github.com/pch/rawmakase/pull/29)).

## Changed

- **Edits with Defringe render differently.** Because Defringe is stronger, photos that already use it now look closer to Lightroom than in 0.1.10.

## Fixed

- **Subfolders of folders added on Windows** show as a tree in the Library instead of one flat entry, and restoring a saved folder includes its subfolders.

## Requirements

Mac downloads require macOS 15+. Windows downloads are for 64-bit Windows 10 and later (x86_64). Linux packages are for x86_64 and ARM (aarch64): Ubuntu 24.04+ or Debian 13+, or Fedora 43+; the Arch Linux package is x86_64. AUR publication remains paused; the Arch package is available directly above. Homebrew users update with `brew upgrade --cask rawmakase`. On Apple Silicon Macs and with the Windows installer, 0.1.10 offers this update in the app.
