RAWmakase 0.1.5 keeps itself up to date and looks more at home on your desktop. It tells you when a new version is out, and on Apple Silicon Macs it can download and install the update for you. The interface can follow a theme, including Omarchy's on Linux, and has sharper text and icons. Previews also respond faster when you edit at 100%.

## New

- **Update notices.** RAWmakase checks GitHub for a new release at launch and then hourly. When one is out, a small notice appears under the toolbar with **Download** and **Skip This Version**. Turn the check off, or run it by hand with **Check Now**, in Preferences › General.
- **One-click updates on Apple Silicon Macs.** Installed from the DMG in Applications, RAWmakase downloads the update, verifies its signature and restarts into the new version. If the new version fails to start, the previous one comes back. Intel Macs and Linux packages get a link to the release page instead.
- **Interface themes.** Preferences › Display › Theme offers RAWmakase's own Lightroom greys (the default), eight built-in themes including Nord, Tokyo Night and Catppuccin, and palette files you add to the themes folder. On Omarchy the interface follows the desktop's theme as it changes. The area behind the photo stays neutral grey in every theme, so colours are still judged against grey.

## Improved

- **Faster editing at 100%.** More of the preview now stays on the GPU, including Clarity, Texture and the Shadows/Highlights map. On a 61-megapixel photo on an M1 Pro Mac, Clarity changes at 100% went from about 750 ms to about 70 ms. Exports are unchanged.
- **Crisper text.** The interface uses Inter, with fixed-width figures so slider values don't shift as they change, and follows your desktop's font smoothing. Names in other scripts use a matching installed font.
- **New icons.** The toolbar, panels and menus use a consistent set of Lucide icons.
- **A Lightroom-style title bar on Mac.** The window controls sit in RAWmakase's own top bar. Drag its empty space to move the window, and double-click it to zoom, as set in System Settings.

## Changed

- **Mac downloads have new file names.** The disk images are now `rawmakase-v0.1.5-macos-arm64.dmg` and `rawmakase-v0.1.5-macos-x86_64.dmg`.
- **Updating from 0.1.4 is still manual.** 0.1.4 has no update check, so download this release once. Later releases will announce themselves.

## Requirements

Mac downloads require macOS 15+. Linux packages are for x86_64: Ubuntu 24.04+ or Debian 13+, Fedora 43+, or current Arch Linux. AUR publication remains paused; the Arch package is available directly above. Building from source now requires Rust 1.98 or newer.
