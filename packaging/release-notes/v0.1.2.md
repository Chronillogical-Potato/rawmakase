RAWmakase 0.1.2 focuses on faster photo browsing and more responsive editing. It adds a choice of RAW demosaic methods, reuses work between preview updates, and fixes color-mixer saturation and several Lightroom import issues. This release also adds signed, notarized Mac installers and ready-to-install Linux packages.

## New

- **Choose how RAW photos are demosaiced.** The Settings menu offers RAWmakase's faster demosaic method and LibRaw's method. Switching reopens the current photo, and your choice is saved for future sessions.
- **Install on Mac without Homebrew.** Separate Apple Silicon and Intel DMGs include the imaging libraries and are signed and notarized by Apple. Linux users get DEB, RPM and Arch packages alongside the portable archive.

## Improved

- **Faster photo browsing.** A disk cache reuses decoded photo data, and neighboring photos are prefetched to reduce repeated work as you move through a folder or catalog.
- **More responsive preview updates.** Fit previews use smaller image levels when appropriate, and color and tone edits reuse cached processing stages. The per-pixel color and tone stage can run on the GPU, with a CPU fallback.
- **Slider previews follow the same processing pipeline as the finished edit.** Interactive previews now use the current pipeline instead of the older draft path, then refine after you stop dragging.

## Fixed

- **Reducing a color's saturation behaves more consistently.** Negative color-mixer saturation now scales linearly, correcting the interpolation used for these adjustments.
- **Older Lightroom edits retain their exposure.** Catalog edits using process versions 2003 or 2010 now import Exposure. Other unsupported legacy tone controls are reported rather than silently dropped.
- **Imported Auto Tone exposure stays consistent.** When Lightroom saved an exposure value, RAWmakase keeps it instead of recomputing it during opening, reset, history or hover previews.
- **RAW decoding can fall back to LibRaw correctly.** Files that cannot use the new sensor-data path no longer fail because LibRaw was asked to unpack them twice.
- **Invalid DNG crop and region bounds are handled more safely.** Bounds checks now account for overflowing dimensions.

## Requirements and limitations

Mac downloads require macOS 15 or later. Linux packages are for x86_64: Ubuntu 24.04+ or Debian 13+ for DEB, Fedora 43+ for RPM, and a current Arch installation for the Arch package. AUR publication remains paused; download the Arch package or the [source recipe archive](https://github.com/pch/rawmakase/releases/download/v0.1.2/rawmakase-0.1.2-arch-recipe.tar.gz) directly.

Preview speed depends on the photo, edits and hardware. These changes do not establish full rendering parity with Lightroom; unsupported legacy tone adjustments still need review after import.
